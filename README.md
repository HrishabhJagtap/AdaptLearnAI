# AdaptLearn AI — 1-Day MVP

**Problem Statement PS-1:** Develop an AI-Based Personalized Learning Content Generator.

A compact Streamlit prototype with **three proficiency levels**, generated explanations, **five MCQs per lesson**, deterministic quiz scoring, and **automatic difficulty adjustment**. No model training required.

## Start on Windows (PowerShell or VS Code terminal)

1. Install Python 3.10+ if necessary, then open this extracted folder in VS Code.
2. Run:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The application opens in your web browser (usually at `http://localhost:8501`).

## Guaranteed offline demonstration (no AI key needed)

- In the sidebar, leave **Demo mode (offline)** selected.
- Keep the topic **Linked Lists**. The demo supports Beginner, Intermediate, and Advanced.
- Click **Generate Personalized Lesson**.
- Switch to **Quiz**, answer five questions, and press **Submit Quiz**.
- Review score, correct answers, and suggested next level.
- Click **Generate Next Adaptive Lesson** to advance/simplify based on performance.
- Switch to **Progress** to show session history.

The offline content is prewritten and curated; it is **not generated by an LLM**. Use it as a backup demo if API access fails. This mode repeats the same topic-level questions; live AI mode generates new ones.

## Enable real AI generation (optional, recommended for PS-1)

1. Get an API key from [Google AI Studio](https://aistudio.google.com/apikey).
2. In the sidebar select **Gemini AI (live)**.
3. Enter the key in the password field; alternatively copy `.env.example` to `.env` and replace the example key (do not share or commit the file).
4. Enter **any learning topic**, then generate a lesson. New lessons, examples, and five quiz questions are generated via the Gemini API.
5. The model name defaults to `gemini-3.8-flash`, documented as a current stable model in Google's model directory (October 2026). If your API key/account lacks access, try an available supported model such as `gemini-3.5-flash-lite` after checking access and pricing.

**Important:** Live API requests require network access and may have quotas or costs. Keep the demo backup ready. Generated explanations/questions should be checked for accuracy before presenting educational content as factual.

## Rule-based adaptive difficulty

- **0–2 correct out of 5:** move one level easier (unless already Beginner).
- **3–4 correct out of 5:** stay at the same level; practice again.
- **5 correct out of 5:** move one level harder (unless already Advanced).

Levels are capped at Beginner, Intermediate, and Advanced. Results are held in Streamlit Session State and **are not permanent**; reloading may reset them. This MVP intentionally does not implement student accounts or a database.

## Files

- `app.py`: Streamlit interface, quiz submission, live Gemini integration
- `engine.py`: curated demo data and deterministic difficulty rules
- `smoke_test.py`: quick consistency tests (run `python smoke_test.py`)
- `PROMPT_AND_REPORT.md`: ready-to-adapt report outline, prompt explanation, and sample lesson outputs
- `requirements.txt`: Python dependencies
- `.env.example`: private API key configuration template

## Quick demo script (2 minutes)

1. Explain the problem: ordinary static notes do not adapt to learner abilities.
2. Show **Beginner → Linked Lists**: simple node-and-head explanation.
3. Complete quiz correctly and show movement to **Intermediate**.
4. Switch to Intermediate content: insertion, deletion, Big-O analysis.
5. Intentionally answer poorly to show return to Beginner.
6. Show score tracking on the Progress tab. If live API is available, demonstrate a new topic to show content generation is genuinely dynamic.

## Day-one scope

This is a **functional prototype**, not a full LMS. Not included: authentication, PDF upload, a permanent database, model fine-tuning, rich teacher analytics, or production reliability. Those are possible future enhancements.
