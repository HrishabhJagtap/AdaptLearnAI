# AdaptLearn AI — Project Notes for PS-1

## 1. Problem statement

Static learning content does not match every student's knowledge level. AdaptLearn AI generates topic-based study explanations and quizzes at a chosen level, assesses understanding, then adapts the next lesson to the result.

## 2. Objective

Develop a small interface that can produce personalized explanations, worked examples, and five MCQs; evaluate results; and vary the next explanation among Beginner, Intermediate, and Advanced.

## 3. Technology used

Python, Streamlit, rule-based adaptation, Google GenAI Python SDK / Gemini API (live mode), and Pydantic for structured response validation. Demo mode uses manually prepared lessons and questions when no API is available.

## 4. System architecture

Student selects topic + level + language + style
→ Streamlit constructs a structured lesson request
→ Gemini API generates lesson and MCQs (or curated offline data is used)
→ Python validates the lesson structure
→ Student takes 5-question MCQ quiz
→ Python computes score and recommends a simpler/same/harder level
→ Next lesson is generated using current level and incorrect-question topics.

## 5. Prompt-design methodology

The main prompt in `app.py` sends the following variables to an existing pretrained LLM:

- Topic: supplied by student
- Proficiency: Beginner / Intermediate / Advanced
- Language: English / Hindi / Hinglish
- Preferred style: step-by-step / analogies / exam revision
- Previously missed quiz concepts: questions answered incorrectly (after first attempt)

It instructs the LLM to return (a) title, (b) overview, (c) three to five key points, (d) worked example, and (e) exactly five MCQs, each with four options, a zero-based correct-answer index, and an explanation. A Pydantic schema requests the structured JSON. Additional Python validation checks the quiz length and answer indices. These checks validate structure, not factual correctness.

### Illustrative prompt excerpt

> You are an accurate, patient university-level tutor. Generate a lesson on Linked Lists. Student proficiency: Beginner. Preferred language: English. Preferred style: step by step. Return a concise explanation, 3–5 key points, one worked example, and exactly five MCQs with answer keys and explanations. Focus on concepts the student previously missed.

The actual application uses a structured response schema and automatically substitutes student preferences.

## 6. Sample outputs across THREE proficiency levels

**The examples below come from the included curated offline demo. They are NOT evidence of an actual Gemini API call. For final evaluation, collect genuine live AI outputs and screenshots after connecting your own API key.**

### Level 1 — Beginner: Linked Lists

- Explanation: A linked list stores values in nodes. Every node contains data and a reference to the next node.
- Example: `10 → 20 → 30 → NULL`.
- Sample MCQ: *What is the first node called?* Answer: **Head**.

### Level 2 — Intermediate: Linked Lists

- Explanation: Insertion, deletion, and traversal work by changing references between nodes.
- Example: Insert 15 after 10: `10 → 15 → 20 → 30`.
- Sample MCQ: *What is the worst-case time complexity of searching an unsorted linked list?* Answer: **O(n)**.

### Level 3 — Advanced: Linked Lists

- Explanation: Floyd's cycle detection, pointer-safe iterative reversal, and dummy nodes are advanced techniques.
- Example: Reverse `1 → 2 → 3 → NULL` into `3 → 2 → 1 → NULL` using prev/curr/next pointers.
- Sample MCQ: *What is the space complexity of Floyd's cycle detection algorithm?* Answer: **O(1)**.

## 7. Difficulty-adaptation algorithm

```
if correct / total <= 0.40:
    new_level = max(0, current_level - 1)
elif correct == total:
    new_level = min(2, current_level + 1)
else:
    new_level = current_level
```

The score thresholds are **prototype design choices**, not research-validated learning measurements. In the live API mode, previously missed questions are passed as context to the next prompt to encourage focused revision.

## 8. Testing plan

- `python smoke_test.py`: validate all offline lessons; confirm correct answer indices and boundaries.
- Begin at Beginner, answer all questions correctly: next level becomes Intermediate.
- Begin at Intermediate, answer no questions correctly: next level becomes Beginner.
- Begin at Intermediate, answer four questions correctly: level stays Intermediate.
- Try live generation with another topic, such as Stacks, and verify difficulty and quiz content.
- Manually check technical accuracy of AI outputs and answer keys.

## 9. Limitations

- No user authentication or durable database; scores are session-only.
- Demo mode works only for Linked Lists; not generated by AI.
- Live mode requires an external API key and functioning network.
- Current adaptation is rule-based, not trained on educational datasets.
- AI-generated content can be wrong, vague, repetitive, or too difficult.
